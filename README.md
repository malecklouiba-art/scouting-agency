# ScoutPro

SaaS de scouting et de recrutement football (MVP web) : recherche de joueurs en langage naturel, fiches joueurs, shortlist et rapports, alimenté par une base PostgreSQL synchronisée depuis Transfermarkt et un moteur conversationnel Gemini.

**État actuel : phase de planification (Étape 1).** Aucun code applicatif n'est encore présent — voir [`docs/architecture-proposal.md`](docs/architecture-proposal.md) pour l'architecture, l'arborescence, le schéma Prisma, les flux Gemini et les écrans proposés avant de démarrer le développement.

Stack cible : Next.js + TypeScript + Tailwind + shadcn/ui, PostgreSQL + Prisma, Supabase Auth/Storage, Google Gemini, déploiement Vercel.
